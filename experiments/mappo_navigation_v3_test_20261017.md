# MAPPO 新场景测试：最佳模型与最终模型

测试日期：2026-10-17。两个模型均已固定，测试结果不用于重新选取检查点。

## 测试方法

- 最佳模型：验证奖励选择的第 1025 回合 best.pt；最终模型：第 2000 回合 latest.pt。
- 使用预留测试种子 30000–30009，与训练种子和固定验证种子无重叠。
- 导航环境版本 3，所有训练时已有 Python 源文件摘要核对一致。
- 两个模型使用相同场景、配置、确定性动作选择、240 步上限；每步为 1 秒仿真时间。
- 在同一进程内逐场景成对运行，每次重置场景随机数；无训练、无参数更新。
- 到达定义沿用训练：车辆距目标不超过 2 米即结束。
- results.json 保存完整配置、各场景几何与摘要、模型文件摘要和全部指标。

## 解读边界

这是 10 个预留场景、一个训练随机种子的测试，样本量较小，不能据此宣称稳定泛化或统计显著优势。固定验证集只有 5 个场景，其成功率不能直接替代新场景成功率。

累计奖励包含探索等项，并且成功回合会提前结束，因此更高累计奖励不等于更高到达率。成功场景平均步数所对应的场景集合也可能不同，应结合逐场景配对结果解读。

失败表示在 240 步内未到达，不代表场景不可完成，也不能仅由这些汇总指标将原因归为无人机策略或无人车导航。
