# vtemp5 车端前视点预训练

vtemp5 用二维局部绕障任务预训练车端选点网络。一个决策步代表 30 个仿真秒。动作是从当前车位看向目标方向的有符号偏角，向左为正。前视点发布后，环境计算这个区间内的车辆运动与探测回传。训练进程可以在 CPU 上直接运行。

## 公里级连续导航

公里导航使用独立的任务模式。默认起终直距为 1,000–1,500 米，车进入最终目标的 2 米半径才算整局到达。穿过第一个或第二个障碍时，继续累计车位、行驶历史和用时。第一阶段 `km-detour` 放置两个左右都能绕的大型陆障。第二阶段 `km-bridge` 先放置陆障，再放置只有一座桥的河。两道障碍分别放在直线路廊全程的 20%–28% 和 60%–68% 处。车上只看到已经回传的当前障碍，目标方向会随车位变化。

训练与评估沿用 `run_vtemp5.py`。通过 `--min-distance-m` 和 `--max-distance-m` 设置起终直距范围，传入等值可测试固定距离。逐图结果记录起终坐标、初始直距、实驶里程、终点余距和各障碍的通过情况。规则基线使用相同的传感回传、物理运动、时间预算和到达判据。

## 完整三机一车微调

在线入口 `run_vtemp5_fleet.py` 从公里级单桥前视点权重初始化。冻结的 v9 MAPPO 控制三架无人机，`vtemp1_connected_anchored` 地面规划器使用车载局部观测和已融合的道路图执行共享航点。车端每 30 秒读取本局实际送达的路网、历史指令和实驶轨迹。收到的航测图块显示前方存在大障碍后，冻结的局部世界模型生成绕行候选。预测路线进入上层选点网络并用于计算该决策周期的可行路线进度。地面执行器继续用观测到的通行证据检查接入道路。

原生占据图块携带通行状态，缺少水面与陆障类别。适配器对世界模型的两种地物条件取等权平均。确认一侧阻断时，连通性检查把未知栅格暂按可通行处理，保留仍可继续探索的通道。用户指定的目标方向为 0°，发布给车机的航点使用同一世界坐标；每次动作和 PPO 概率都在车辆坐标系进行一致的换算。

首次在线运行包含短时接口预检、冻结初始车端的整程基线、另一组地图上的整程 PPO 采样和更新，以及原基线地图和机群种子的复测。每张原生公里地图含一处主要障碍，课程包含双侧可绕的湖泊和只有一座桥的河道。预检单独核对实际收包、路网融合与动作概率。更新只作用于车端，预检时间截断与整程到达分别记录。

## 两阶段课程

1. 车接近一块横跨直达线的大型陆地障碍。两侧都能绕行；训练目标是选择并持续跟随一侧，接回障碍后的道路。
2. 车接近一条只有一座桥的河。桥的实际位置分布在两侧。无人机探测由受前视指令影响的延迟回包模拟。当前侧被实测证伪后，策略可以换边并尝试沿另一侧通过。

对两阶段各 32 张独立地图进行了 2 米栅格的连通性核验。陆障图全部左右可绕；河流图有 16 张只通左侧、16 张只通右侧。在障碍纵深中段，绕开陆障至少需偏离初始直达线 100 米，通过河流至少需 104 米。首次用于打通训练链路的较小场景保留为 `--terrain local`。[地图核验](../../../artifacts/vtemp5-large/geometry.json) · [地图示例](../../../artifacts/vtemp5-large/curriculum-maps.png)

## 世界模型

大障碍首次回传后，每隔 30 个仿真秒，模拟器先合并截至该时刻已送达的观测，再让冻结的世界模型在一次前向计算中预测左右两侧。车端选点网络随后读取这一拍的路线、实测标记和通行概率，结合当前车位和历史发布前视点。即使本周期没有新回包，也会进行一次推理；证据相同，地形预测可以相同。两次选点之间，用发令时的参考路线结算这段车辆运动。首轮课程实验曾按新回包刷新地形预测，车端选点周期同为 30 秒。

首次障碍报告触发一个局部预测网络。它用已回传的局部边界、坡度和所探一侧的观测，预测通道横向位置、障碍纵深及该侧可通行的概率。每个样本的标签来自同回合后来收到的实测报告，未知量不计入损失。每阶段 128 张训练地图，每张分别向左、向右探查。第二阶段在第一阶段权重上继续训练，并重放第一阶段样本。选点训练期间冻结相应世界模型，预测路线和已测标记一起进入车辆决策图。

在每阶段独立的 32 张地图上，对仍未直接测到的几何量评估。双侧陆障和单桥的横向位置平均绝对误差分别为 5.63 米、5.93 米；以训练集均值预测，误差分别为 10.97 米、10.96 米。单桥首报时的平均可通概率为 52.7%，桥侧身份需继续探查。收到明确通行报告后，系统直接采用实测结论。[陆障预测评估](../../../artifacts/vtemp5-large/world-detour/evaluation.json) · [单桥预测评估](../../../artifacts/vtemp5-large/world-bridge/evaluation.json)

## 观测和奖励

策略只能读取当时已经送达的观测。首次大障碍报告到达后，局部路线预测才参与决策。候选路线的图节点区分实测与预测，车根据前视指令尝试推进。对同一个障碍，已选绕行侧持续保留，有封闭证据后才能换边。执行器维持锁定的次数与网络主动请求换边的倾向需要分别解释。

推进分按发布前视点时的参考路线和执行前后的实际模拟车位结算。单障碍局部课程以车辆通过障碍并到达对侧出口为成功，公里课程以整程到达为成功。小障碍对行车的影响由运动近似吸收。远方目标用于确定选点的零度方向。

## 校准

在仓库根目录运行下面的命令可重建本次使用的运动校准文件。

```bash
python src/teamed-planning/scripts/simulator/vtemp5_calibration.py
```

正式校准覆盖 vtemp4 圆障碍训练第 1、8、15、22 次更新的全部 64 局，共 8,342 个完整的 30 秒区间。有运动的区间净位移中位数为 6.209 米，累计行驶不超过 1 厘米的区间占 2.89%。这 64 局均在时间预算耗尽时结束。修复诊断中的两个到达回合净位移中位数为 13.822 米，提示运动尺度随控制器和任务分布变化。不同批次的分位数和源文件校验值保存在 [校准结果](../../../artifacts/vtemp5-pilot/calibration.json)。探测范围、回传时序和障碍形状是轻量模拟器的假设。

## 运行入口

在 `teamedplanning-2d` 环境从仓库根目录运行。重建世界模型时，选择新的输出目录。策略训练支持从前一阶段的检查点初始化，记录世界模型哈希、示范地图、PPO 训练地图和留出地图的种子范围。

```bash
python -I src/teamed-planning/scripts/simulator/run_vtemp5_world_model.py --output artifacts/vtemp5-reproduction
python -I src/teamed-planning/scripts/simulator/run_vtemp5.py --help
python -I src/teamed-planning/scripts/simulator/evaluate_vtemp5_switch.py --help
```

全系统迁移时，需要把实际回传转换为相同的障碍状态和路线输入。轻量环境中的通过率仅衡量合成局部任务。

## 首次课程实验结果

两个阶段沿用同一车端网络。第一阶段使用公开路线教师示范初始化；在 24 张开发图上，初次 PPO 训练的确定性策略从示范后的 24/24 降为 5/24。从示范权重出发，将 PPO 学习率由 0.0003 降至 0.00002 后恢复为 24/24，以这个检查点进入单桥阶段。第二阶段加入封路后车辆实际到达的状态、基于最新回传的局部参考点，以及针对大角度换边的示范损失。冻结末次网络后进行了以下独立测试。

| 测试 | 通过 | 条件 |
| --- | ---: | --- |
| 第一阶段网络，双侧大障碍 | 64/64 | 64 张新图，网络从起点自主选点 |
| 第二阶段网络，单桥 | 23/64 | 64 张新图，30 局收到已选侧封闭的证据，5 局换边，这 5 局均未最终过桥 |
| 第二阶段网络，重测双侧障碍 | 54/64 | 使用第二阶段世界模型和策略，在第一行的同一批地图测试 |

另外用 32 个新地图种子做成对回传测试。每个种子各做一次起初沿左和起初沿右的探查。每一对的动作和车迹相同，交给策略时只有通行报告及由它更新的观测不同。当前侧畅通时，64 对均保持原侧。当前右侧封闭时，32/32 在下个决策周期换向左侧，其中 11 局最终通过；当前左侧封闭时，0/32 换向右侧。执行器负责无反证时锁侧。这个结果表明现有策略仍有明显方向偏差，已证伪后的换边和持续行车仍需训练。
