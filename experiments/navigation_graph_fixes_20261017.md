# 导航图建图修复与验证（环境版本4）

代码修复完成。63项回归测试通过。固定实际送达原始观测重建12个失败场景，任务图全部连通；真实几何独立检查的越界/净空违规节点与边均为0。原始模型文件的SHA256已再次核对，未发生变化。

## 改动

1. 采样边界由障碍物净空决定，不再按最大边长的一半裁剪视野。节点间距同时受最大边长和视野尺寸限制。
2. 保留骨架端点，在已观测安全区域内补充支撑节点，覆盖开阔区域与跨视野衔接位置。
3. 每帧检查可见旧节点，优先连接不同分量，已有邻居度数不会阻止必要的桥接。保持只有实际观测支持的连接，未使用真值补图。
4. 对连续世界坐标线段与膨胀后的占据像素矩形进行相交检查，禁止未知区域连接；节点本身也使用同样的净空检查。避免将旧节点量化到像素中心后漏检。
5. 2D建图净空与地面导航统一为1.5米；ROS等其他调用保留3米默认值。2D建图使用已知世界边界，禁止产生越界节点。
6. 新增任务图连通性、首次连通步数、物理路径长度、相对直线距离比和图规模指标。端点接入上限10米，必须有实际送达自由空间观测支持；内部使用实际收到的边。指标不使用障碍物真值。首次连通检查在图更新及每5步执行，因此存在最多4步检查延迟。
7. 检查点选择优先任务图连通率，再考虑首次连通时间和绕行比，并保留碰撞惩罚。训练奖励和Actor输入维度不变。
8. 批量计算邻近查询、边走廊几何和候选位置的局部节点特征，减少图变大后的重复计算。

环境版本已从3升级为4，恢复训练会拒绝混用旧环境检查点。启动脚本默认使用新的v4输出目录。旧模型跨环境评估由单独的显式迁移评估脚本执行。
